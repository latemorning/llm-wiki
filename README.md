# Dev Wiki

이 폴더는 Obsidian에서 쓰는 개발 지식 위키이면서, LLM에게 필요한 맥락을 빠르게 전달하기 위한 LLM wiki입니다.

시작점은 [[Home]]입니다.

## 구조

- `00 Inbox`: 아직 정리되지 않은 임시 메모
- `01 Maps`: 위키 탐색 지도와 MOC
- `10 Projects`: 프로젝트 단위 문서
- `20 Systems`: 시스템, 서비스, 모듈 설명
- `30 Concepts`: 재사용 가능한 개념 설명
- `40 Runbooks`: 반복 작업 절차와 명령어
- `50 Decisions`: 중요한 결정 기록
- `60 Prompts`: 재사용 가능한 LLM 프롬프트
- `70 Sources`: 외부 출처와 조사 로그
- `80 Context Packs`: LLM에게 붙여넣기 좋은 맥락 묶음
- `90 Templates`: 새 노트 템플릿
