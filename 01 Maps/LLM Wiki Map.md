# LLM Wiki Map

## 목적

이 위키는 개발 지식을 Obsidian 링크로 연결하고, LLM에게 넘길 수 있는 작은 맥락 묶음으로 재가공한다.

## 핵심 영역

- [[Project Map]]: 프로젝트별 진입점
- `20 Systems`: 시스템과 모듈 단위 설명
- `30 Concepts`: 반복해서 쓰는 개념
- `40 Runbooks`: 명령어와 절차
- `50 Decisions`: 기술 결정 기록
- `60 Prompts`: 재사용 프롬프트
- `70 Sources`: 근거와 조사 기록
- `80 Context Packs`: LLM 입력용 요약 묶음

## LLM에게 넘기는 순서

1. 관련 context pack
2. 프로젝트 노트
3. 필요한 결정 기록
4. 필요한 런북
5. 필요한 출처

## 좋은 노트의 기준

- 제목만 보고 역할을 알 수 있다.
- 현재 상태, 근거, 다음 행동이 분리되어 있다.
- 긴 설명보다 링크와 짧은 요약을 우선한다.
- 오래된 내용은 `status: stale` 또는 `Needs update`로 표시한다.
