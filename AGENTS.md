# LLM Agent Instructions

This folder is an Obsidian-based development wiki. When using it as context, start with `Home.md`, then read the relevant map in `01 Maps`, then use a focused context pack from `80 Context Packs`.

## Reading Order

1. `Home.md`
2. `01 Maps/LLM Wiki Map.md`
3. A relevant project note in `10 Projects`
4. A relevant context pack in `80 Context Packs`
5. Supporting runbooks, decisions, systems, and sources only when needed

## Editing Rules

- Preserve existing user notes unless explicitly asked to reorganize them.
- Keep context packs short, current, and task-oriented.
- Do not store secrets, credentials, personal data, tokens, or production-only values in this wiki.
- Mark uncertain information as `Assumption` or `Needs verification`.
- Prefer linking to source notes instead of copying long external content.
- When a project fact changes, update the project note and any affected context pack.

## Note Types

- `project`: product or codebase overview
- `system`: service, module, or architecture area
- `concept`: reusable technical concept
- `runbook`: repeated procedure
- `decision`: accepted or rejected technical decision
- `prompt`: reusable LLM instruction
- `source`: external or local source record
- `context-pack`: concise LLM-ready context bundle
